# 🌐 Personal Portfolio Website

## 📌 About the Project

This is a Personal Portfolio Website developed using Django, Python, HTML, CSS, and JavaScript.

The purpose of this project is to showcase my personal information, skills, projects, and contact details through a simple and responsive website.

## ✨ Features

- Personal Home Page
- Profile Picture and Introduction
- Skills Showcase
- Projects Showcase
- Project Details
- Login and Registration Pages
- Contact Information
- Responsive Design
- Django Admin Panel for Managing Projects

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Git & GitHub

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd Personal
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

For Windows PowerShell:

```powershell
venv\Scripts\Activate.ps1
```

### 5. Install Required Packages

```bash
pip install -r requirements.txt
```

### 6. Apply Database Migrations

```bash
python manage.py migrate
```

### 7. Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

http://127.0.0.1:8000/
